# Final Vote

A voting web app backed by Firebase (project: `voting-10a21`).

## Setup

```bash
npm install
npm run dev
```

Open the printed local URL — the page confirms the Firebase connection.

## Structure

- `src/firebase.js` — initializes the Firebase app, Firestore (`db`), and Analytics
- `src/main.js` — app entry point
- `index.html` — page shell (Vite entry)

## Build

```bash
npm run build
```
